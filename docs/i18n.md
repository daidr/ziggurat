# 本地化

`ziggurat_i18n` 是可选纯 Zig 模块，提供语言标签、回退与协商、消息 catalog、plural/select 消息、复数规则、数字与日期格式化、伪本地化和书写方向查询。模块不持有 App、Window、线程或全局状态；catalog 的内存来自调用者传入的 allocator，格式化写入调用者的 `std.Io.Writer`，不在格式化路径分配。只有 `locale.system()` 读取操作系统设置。

```zig
const i18n = @import("ziggurat_i18n");

const english = [_]i18n.Entry{
    .{ .key = "files", .message = "{count, plural, =0 {No files} one {# file} other {# files}}" },
    .{ .key = "greeting", .message = "Hello, {name}!" },
};
comptime i18n.catalog.comptimeValidate(&english); // 坏消息在构建期失败

var catalog = i18n.Catalog.init(allocator, try i18n.Locale.parse("en"));
defer catalog.deinit();
try catalog.addEntries(try i18n.Locale.parse("en"), &english, null);
try catalog.addJson(try i18n.Locale.parse("de"), german_json, &diagnostic);

const preferred = i18n.locale.system() orelse i18n.Locale.root;
const localizer = i18n.Localizer.init(&catalog, catalog.negotiate(&.{preferred}), .{});
const text = try localizer.bufPrint(&buffer, "files", &i18n.args(.{ .count = 3 }));
```

## 语言标签与回退

`Locale.parse` 接受 `-` 或 `_` 分隔、大小写不敏感的 BCP 47 标签，以及 POSIX 的 `.codeset`、`@modifier` 后缀。结果规范为小写语言、首字母大写脚本、大写地区和小写变体；扩展与私用子标签被忽略，`und`、`root`、`C`、`POSIX` 是 root。标签最长 32 字节，`Locale` 是可复制的值。

`fallbackChain` 从最具体到语言本身列出候选，不含 root：`de-CH-1996 → de-CH → de`。没有显式脚本时用小型 likely-script 表推断：`zh-TW → zh-Hant-TW → zh-Hant`。非默认脚本不回退到裸语言，所以 `zh-Hant` 不会落到简体 `zh`，`sr-Latn` 不会落到西里尔 `sr`。

`negotiate(requested, available)` 按用户偏好顺序处理：先在每个偏好的回退链里找完全匹配，再找语言与有效脚本都相同的可用项（`en` 选中 `en-US`，`zh-HK` 选中 `zh-TW`）。`Catalog.negotiate` 在无匹配时返回 source locale。

`direction()` 按显式或推断脚本返回 `.ltr`/`.rtl`（Arab、Hebr、Thaa、Syrc 等为 RTL），伪地区 `XB` 也是 RTL。模块只报告方向；控件的镜像布局属于 UI/视图层，尚未实现。

`locale.system()` 在 Linux 依次读取 `LC_ALL`、`LC_MESSAGES`、`LANG`，Windows 调用 `GetUserDefaultLocaleName`，其他平台返回 null。它在调用时读取，不缓存，也不监听设置变化。

## 消息语法

消息是 ICU MessageFormat 的常用子集：

- `{name}`：字符串原样写出，数字按 locale 格式化，`Instant` 用短日期时间。
- `{n, number}`、`{n, number, integer}`、`{n, number, percent}`。
- `{t, date}`、`{t, time}`，可选 `short|medium|long|full`，默认 medium。
- `{n, plural, [offset:N] =N {...} zero|one|two|few|many {...} other {...}}`，以及同样形式的 `selectordinal`。精确 `=N` 优先于类别，类别按 `n - offset` 选择，分支内 `#` 写出 `n - offset` 的格式化数字。
- `{s, select, key {...} other {...}}`。
- `''` 表示撇号；撇号紧接 `{`、`}`、`|` 或 plural 内的 `#` 时开始引用文本，直到下一个单独撇号；其他撇号按字面输出。

`other` 分支必须存在，类别/select 键不能重复，参数名为 ASCII 字母、数字和下划线，嵌套最多 8 层，消息最长 16 KiB。`message.validate` 只检查语法；`comptimeValidate` 在编译期报错。`format` 先完成校验，语法错误不写出任何内容；参数缺失（`MissingArgument`）、类型不符（`ArgumentType`）、偏移溢出或日期越界（`OutOfRange`）以及 writer 已满（`WriteFailed`）明确返回错误，此时 writer 可能已有前缀输出。

`args(.{ .count = 3, .name = "Ana" })` 在调用点把整数、浮点、字符串、`Instant` 或 `Value` 字段转换为参数数组。RTL locale 中字符串参数默认包在 U+2068/U+2069 隔离符中，可用 `isolate_arguments = false` 关闭。

## Catalog 与 Localizer

`addEntries` 借用条目字符串（通常是编译期常量），只分配排序后的索引；`addJson` 复制一个字符串值的 JSON 对象，嵌套对象用 `.` 展平。每条消息在加入时校验；空键、控制字符、超过 256 字节的键、非 UTF-8、重复键（包括展平后重复）、非字符串值、超过 8 层的嵌套或超过 16 MiB 的输入会使整次加入失败，catalog 保持不变，`Diagnostic` 记录出错的键。同一 locale 只能加入一次，最多 64 个 locale、每个 65536 条。

`Localizer.init` 一次解析 bundle 链：显示 locale 的回退链，然后是 source locale 的链。之后每次格式化只是逐链二分查找加写出，不分配。消息来自显示 locale 自己的链时用显示 locale 格式化（`de-CH` 用户读到 `de` 消息时数字仍是 `1’200`）；落到 source 回退时用 source 的复数规则、数字和日期，避免英文句子里出现另一种语言的日期。缺失键默认写出键名，`missing = .fail` 返回 `MissingMessage`。提供 `format`、`bufPrint` 和调用者拥有结果的 `allocPrint`。

Catalog 构建完成后只读，可被多个线程上的 Localizer 共享；加入 bundle 需要独占访问。Localizer 保存 catalog 指针，catalog 必须比它活得久；之后加入的 bundle 不会出现在已有 Localizer 的链里。

## 复数、数字与日期

复数规则内置约 50 种语言的基数规则族（英语、德语等 one/other，法语与葡萄牙语的 0–1 和百万 many，俄语、波兰语、捷克语、阿拉伯语、希伯来语、爱尔兰语、威尔士语等）以及英语、法语、意大利语、瑞典语的序数规则；未列出的语言总是 `other`。操作数从显示出来的十进制文本计算，因此英语里 `1` 是 one 而 `1.0` 是 other。

数字格式化使用列出 locale 的小数点、分组符、负号、百分号、数字集和分组规则（印度 3;2 分组、西班牙语/波兰语四位数不分组、阿拉伯语和波斯语本地数字），未列出的 locale 用 `1,234.5`。浮点数先取最短往返十进制表示，再按四舍六入五成双舍入到 `max_fraction`（默认 3，最多 15），百分比在十进制文本上移位而不做二进制乘法。货币样式只放置调用者给出的符号或代码，不含货币数据或各币种默认小数位。

日期用公历，范围为 0001–9999 年。`Instant` 带调用者给出的 UTC 偏移（最多 ±18 小时）；模块没有时区数据库，long/full 时间样式没有时区名，与 medium 相同。内置 en、en-GB、de、fr、es、it、pt、ru、ja、zh、zh-Hant、ko 的月份/星期名称和 short/medium/long/full 模式，其他 locale 使用数字 ISO 风格。`date.formatPattern` 支持 y、M/L、d、E/c、a、h、H、m、s 和引用文本，未知字母返回 `InvalidPattern`。内置数据参照 CLDR 的常见形式手工整理，不是完整 CLDR，也不跟随系统区域设置的自定义格式。

`number.parseFloat(locale, text)` 读回格式化的数字：接受 locale 的负号、`-`、`+` 与 U+2212，ASCII 或 locale 数字，只在小数点前出现的分组符，locale 的小数点（分组符不是 `.` 时也接受 `.`），并去掉首尾空格；其他文字返回 `InvalidNumber`。`date.hourCycle(locale)` 从短时间模式判断 12/24 小时制，`date.formatMonthYear` 写日历标题式的月份与年份（俄语用独立格月份名）。`week.weekFor(locale)` 按地区（没有地区时取语言最可能的地区）给出一周第一天和第一周至少包含的天数，`week.weekOfYear` 按这套规则计算周数及其所属年份；地区表参照 CLDR 的周数据手工整理。

## 生成的访问器

应用的消息也可以放在 `<tag>.json` 目录文件里，由 `ziggurat generate` 检查并生成 Zig 与 TypeScript 两侧带类型的访问器，`ziggurat i18n check` 列出问题，见 [ziggurat 命令](cli.md#generate)。工具通过两个公开函数读取消息：`message.visit(pattern, visitor)` 与 `validate` 做同样的语法检查，并按出现顺序告诉 visitor 每个参数的用法（`Kind`：simple、number、date、time、plural、selectordinal、select）以及 plural、selectordinal、select 的每个分支键；`plural.cardinalCategories(rules)` 与 `plural.ordinalCategories(locale)` 返回规则实际会选中的类别集，由整数、百万与一两位小数取样得到。

## 伪本地化

`en-XA` 选择 accented：替换 ASCII 字母、用 `[...]` 包住消息并按字面文本长度补约 40% 的 `~`，用于发现硬编码字符串、截断和字形问题。`ar-XB` 选择 bidi：消息前后加 RLM，字面文本放入 RLO/PDF，用于检查 RTL 布局。参数值不被改写。伪 locale 使用 source 消息；`LocalizerOptions.pseudo` 可显式选择或关闭模式，`pseudo.transform` 处理不是消息模式的普通文本。

## 验证

`zig build test-i18n` 已接默认 test/check。测试覆盖标签规范化与非法输入、脚本感知的回退链与协商、方向、各复数规则族样本与序数、分组/最小分组/本地数字、五成双舍入与进位、百分比/货币、公历换算边界与偏移、各内置 locale 的日期样式与模式引用、消息的 plural/offset/selectordinal/select 嵌套/引用/日期、语法错误不产生输出、参数类型与容量错误、伪本地化与 RTL 隔离、catalog 回退与缺失键、失败加入不改变 catalog，以及全部分配失败路径无泄漏。纯数据检查不替代母语审校或与完整 CLDR 的逐项比对。
